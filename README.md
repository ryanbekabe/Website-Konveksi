# Website-Konveksi

Platform web untuk bisnis konveksi (kaos, kemeja, jaket, seragam, hoodie, dll.) yang mencakup:

- **Company profile & katalog** produk dan portofolio
- **Pemesanan online** untuk produk ready stock maupun custom (sablon/bordir)
- **Manajemen produksi**: pelacakan status dari desain hingga pengiriman
- **Dashboard admin**: produk, pesanan, pembayaran, stok bahan, pelanggan, dan laporan

## Status

Tahap perancangan. Belum ada kode aplikasi.

## Dokumentasi

- [Rancangan Program](RANCANGAN_PROGRAM.md): fitur, alur bisnis, arsitektur, rancangan database dan API, roadmap, pengujian, dan risiko.

## Rencana Teknologi

Frontend Next.js + Tailwind CSS, backend Laravel atau Node.js, database MySQL/PostgreSQL, Redis, dan integrasi payment gateway, ongkir, serta WhatsApp. Detail lengkap ada di dokumen rancangan.
